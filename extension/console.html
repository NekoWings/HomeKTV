HomeKTV播放电脑 · 主机设置

SET UP ONCE. SING TOGETHER.

这台电脑，负责把歌唱响。

扩展装在连接音箱 / 电视的电脑上。朋友只需手机扫码，不用安装插件。

  1. 01
    先运行服务

    在本机 HomeKTV 文件夹运行 npm start

  2. 02
    扩展自动当主机

    首次连接后自动准备播放，无需再点接管

  3. 03
    去点歌，邀请朋友

    自动打开点歌页，手机在同一 Wi-Fi 扫码

准备好，开始今晚的第一首

默认连接本机服务。以后打开扩展会自动恢复主机。

连接设置 端口 / 口令 / 其他电脑

通常不用改。服务在另一台电脑时，填写它的局域网地址。

浏览器扩展无法替你启动 Node 服务。先运行终端命令，再点击上方按钮。

浏览偏好

在视频和搜索结果旁快速点歌，仅影响本浏览器。

等待启动

本机播放状态

连接成功后，这台电脑会自动成为播放主机。

主机控制台保持打开即可，日常点歌在网页完成。歌曲会在独立播放窗口显示。

NOW SINGING

还没连接房间

启动后自动打开点歌页。

首次有声播放可能需要在视频页点击「开始唱 / 允许声音」。关闭本控制台会停止主机播放。

启动后自动处理朋友的搜歌请求

主机电脑装扩展 · 朋友手机打开网页 · 同一 Wi-Fi，一起唱
